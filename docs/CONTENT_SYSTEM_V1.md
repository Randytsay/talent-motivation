# Content System V1 — 參加者結果文案與解讀規則

版本：V1.0 Draft  
用途：避免前端或 AI 在缺少文案時自行發明人格、職涯或商業結論。

---

## 1. 核心原則

本系統不是心理診斷，也不以生命靈數判定命運、能力、健康、財富或職業適性。

固定語言原則：

- 可以說：`可能`、`容易被...吸引`、`值得留意`、`可以探索`、`哪一段最像現在的你？`
- 不要說：`你就是`、`你天生注定`、`你的天命`、`你一定適合`、`這證明你`。
- Life Path = 象徵性自我反思入口。
- RIASEC = 職涯興趣與活動偏好，不等於能力測驗。
- 第三面鏡子 = 本人主觀現況，不轉換成科學比例推論。

固定總結句：

> 沒有任何一個測驗可以定義你，但當不同的鏡子都照到同一個地方，那裡就值得你好好看一看。

## 2. Life Path V1 內容

每個數字只提供四種內容：

1. 容易發光
2. 容易耗能
3. 核心原動力
4. 給自己的問題

### 1｜開創者

關鍵字：自主、開始、行動、主導

- 容易發光：在需要開局、做決定、承擔責任或把想法變成第一步時，通常比較有精神。
- 容易耗能：長期只能等待指令、沒有決定空間，或明明知道可以改進卻無法行動時，可能特別消耗。
- 核心原動力：創造與主導。
- 給自己的問題：`現在的生活裡，有多少事情是我真正可以自己做決定的？`

### 2｜連結者

關鍵字：合作、關係、傾聽、協調

- 容易發光：在促成合作、照顧關係、理解不同立場或讓團隊更和諧時，通常能發揮價值。
- 容易耗能：長期處於高衝突、缺乏互信，或必須完全單打獨鬥的環境，可能比較辛苦。
- 核心原動力：關係與和諧。
- 給自己的問題：`哪些關係，會讓我感覺自己被理解，也能真正貢獻？`

### 3｜表達者

關鍵字：表達、創意、分享、被看見

- 容易發光：在分享想法、說故事、創作、溝通或讓氣氛活起來時，通常比較有能量。
- 容易耗能：長期不能表達自己的想法、工作高度單調，或所有事情都只能照固定方式進行時，可能感到壓抑。
- 核心原動力：表達與被看見。
- 給自己的問題：`我現在有多少空間，可以把自己的想法說出來或做出來？`

### 4｜建構者

關鍵字：穩定、結構、紀律、完成

- 容易發光：在建立流程、把混亂整理好、持續完成長期任務或打造可靠基礎時，通常很有價值。
- 容易耗能：方向反覆改變、規則不清楚、承諾沒有落實，或事情永遠停留在想法階段時，可能特別疲累。
- 核心原動力：穩定與完成。
- 給自己的問題：`我現在建立的，是讓自己更安心的秩序，還是只是在維持習慣？`

### 5｜探索者

關鍵字：自由、變化、好奇、溝通

- 容易發光：在接觸新事物、移動、變化、溝通、嘗試不同方法或擁有自主空間時，通常比較有精神。
- 容易耗能：高度重複、長期沒有變化、缺乏自主，或被限制只能用一種方式做事時，可能容易失去動力。
- 核心原動力：自由與體驗。
- 給自己的問題：`我的生活裡，還剩多少探索新可能的空間？`

### 6｜守護者

關鍵字：照顧、責任、品質、價值感

- 容易發光：在照顧人、提升品質、承擔責任、讓環境更舒服或讓重要的人被支持時，通常容易感受到價值。
- 容易耗能：長期付出卻沒有界線、責任過度集中，或只剩義務而失去自己的需要時，可能特別累。
- 核心原動力：付出與價值感。
- 給自己的問題：`我現在的付出，有沒有也留一點空間照顧自己？`

### 7｜洞察者

關鍵字：理解、深度、思考、獨立

- 容易發光：在研究、分析、理解本質、獨立思考或深入一個複雜問題時，通常容易進入專注狀態。
- 容易耗能：太多表面社交、資訊混亂、沒有時間思考，或被要求只接受答案不能追問原因時，可能較消耗。
- 核心原動力：理解與深度。
- 給自己的問題：`現在的工作與生活，還有多少事情能讓我真正想明白？`

### 8｜成就者

關鍵字：成果、影響、資源、目標

- 容易發光：在有明確目標、可以影響結果、整合資源、承擔更大責任或看到成果時，通常容易被驅動。
- 容易耗能：努力與成果完全無法連結、沒有成長空間，或長期無法影響重要決策時，可能感到受限。
- 核心原動力：成果與影響力。
- 給自己的問題：`我現在投入的努力，有沒有逐漸累積成我真正重視的成果？`

### 9｜理想者

關鍵字：意義、同理、貢獻、視野

- 容易發光：在看見更大的意義、幫助群體、連結不同觀點或讓事情對更多人產生正向影響時，通常比較有感。
- 容易耗能：長期只做自己不認同的事情、缺乏價值感，或一直付出卻無法放下時，可能容易疲憊。
- 核心原動力：意義與貢獻。
- 給自己的問題：`我現在做的事情，和我真正重視的價值有多靠近？`

### 11｜啟發者

關鍵字：直覺、啟發、連結、敏銳

- 容易發光：在捕捉新觀點、啟發別人、感受細微變化或把抽象想法轉成能被理解的訊息時，可能特別有感。
- 容易耗能：刺激過多、期待過高、長時間無法沉澱，或一直承接別人的情緒與期待時，可能比較容易過載。
- 核心原動力：啟發與連結。
- 給自己的問題：`哪些想法或經驗，是我很想整理後分享給別人的？`

### 22｜實踐者

關鍵字：願景、系統、落地、長期

- 容易發光：在把大方向拆成可執行步驟、整合人與資源、建立系統或推動長期成果時，通常容易感受到成就。
- 容易耗能：目標很大但沒有落地路徑、責任過多，或自己對完成度要求過高時，可能形成壓力。
- 核心原動力：把理想變成現實。
- 給自己的問題：`我心裡那件很想完成的事，下一個可以落地的小步驟是什麼？`

### 33｜賦能者

關鍵字：陪伴、成長、影響、服務

- 容易發光：在教學、陪伴、支持人成長、整合經驗並轉化成他人可以使用的方法時，可能很容易感受到意義。
- 容易耗能：把所有人的問題都扛在自己身上、責任沒有邊界，或總覺得自己還做得不夠時，可能特別累。
- 核心原動力：幫助人成長。
- 給自己的問題：`我能不能在幫助別人的同時，也保留自己的界線與能量？`

## 3. Life Path Resonance

固定問法：

`剛才的描述，和現在的你有多接近？`

選項：

- 很像
- 有一點
- 不太像

第二問：

`哪一句最像現在的你？`

原則：本人回饋的優先級高於生命靈數文字本身。

## 4. RIASEC 結果文案

### R｜實作型 Realistic｜做

- 核心原動力：把事情真正做出來，看見具體成果。
- 容易有精神：實作、操作、現場問題、清楚任務、看得見成果。
- 容易耗能：長時間空談、反覆開會卻沒有行動、成果太抽象。
- 可以探索：工程技術、維運、設備、專案執行、實務服務、技術教學、把專業變成服務。
- 反思題：`我現在每天花最多時間的事情，最後看得到成果嗎？`
- 講師提示：`R 高不是不喜歡想，而是想完通常希望能做。`

### I｜研究型 Investigative｜想

- 核心原動力：理解真正原因。
- 容易有精神：學習、分析、研究、比較、找規律、解複雜問題。
- 容易耗能：只要求照做、不允許追問、資訊混亂或長期只做表層互動。
- 可以探索：研究、工程、IT、資料、分析、顧問、診斷、知識內容、AI 應用。
- 反思題：`現在的工作，還有多少事情能讓我保持好奇？`

### A｜創意型 Artistic｜創

- 核心原動力：表達自己，創造不同可能。
- 容易有精神：自主、創作、表達、設計、故事、嘗試不同做法。
- 容易耗能：高度重複、方法固定、沒有創意空間、限制過多。
- 可以探索：設計、內容、品牌、媒體、行銷、教育、創作、短影音、個人品牌。
- 反思題：`我的生活裡，還有多少空間可以加入自己的想法？`
- 講師提示：`A 高不代表一定會畫畫；Artistic 指的是更廣義的創造與表達。`

### S｜助人型 Social｜幫

- 核心原動力：因為人而產生價值感。
- 容易有精神：互動、傾聽、陪伴、教學、分享、看見人成長。
- 容易耗能：長期孤立、只剩數字與流程、感受不到對人的影響。
- 可以探索：教育、顧問、服務、醫療照護、人資、教練、社群、培訓、客戶成功。
- 反思題：`我現在做的事情，有沒有讓我感受到自己對別人有價值？`

### E｜推動型 Enterprising｜帶

- 核心原動力：影響事情往前走。
- 容易有精神：有目標、有挑戰、能影響結果、整合人與資源、推動事情。
- 容易耗能：沒有決策空間、只能被動等待、努力無法影響結果。
- 可以探索：管理、業務、專案領導、行銷、顧問、組織發展、資源整合、商業模式探索。
- 反思題：`我現在有多少機會，可以真正影響自己的結果？`
- 講師提示：`E 高不等於一定要當老闆，核心是希望自己的行動能影響結果。`

### C｜組織型 Conventional｜整

- 核心原動力：把混亂變有秩序。
- 容易有精神：整理、規劃、流程、標準、資料、精準、讓事情更有效率。
- 容易耗能：規則一直改、責任不清、資訊混亂、沒有可控流程。
- 可以探索：行政、財務、營運、品質、專案管理、資料、流程、供應鏈、後台營運。
- 反思題：`我現在是在維持秩序，還是在建立更好的秩序？`
- 講師提示：`C 常被低估，但少了這類型，很快就會出現「奇怪，怎麼又漏掉了？」`

## 5. RIASEC 組合呈現

UI 顯示 Top3 code，但一定同時翻成自然語言。

建議 mapping：

- S + E + A → `人 × 影響 × 創造`
- E + S + C → `推動 × 人 × 組織`
- I + R + C → `分析 × 實作 × 秩序`
- A + S + E → `創造 × 人 × 推動`
- R + I + C → `實作 × 分析 × 系統`

若沒有預先定義的組合，不要硬套人格名稱；直接用 Top3 的核心動詞組合：

`做 / 想 / 創 / 幫 / 帶 / 整`

例如 `IAS`：`想 × 創 × 幫`。

## 6. 主觀能量與測驗結果的比較

若 `self_energy_choice == top1`：

> `你的直覺選擇和測驗最高向度剛好一致，這是一個值得留意的重複線索。`

若不同：

> `你的直覺選擇和測驗最高向度不完全相同。這不代表哪一個錯了，反而可以看看：哪一個比較像現在的你？`

不得寫成「測驗比本人更準」。

## 7. Third Mirror 動態文字

20%：`你感覺目前能發揮自己的空間還不算多，值得看看哪些優勢一直沒有機會被使用。`

40%：`你感覺目前大約只發揮了一部分，也許已有一些優勢正在使用，但還有其他面向值得探索。`

60%：`你感覺現在已經有不少發揮空間，同時仍可能存在幾個你希望增加的部分。`

80%：`你感覺目前多數優勢都有機會被使用，可以再看看什麼會讓你從「不錯」走向「更適合自己」。`

100%：`你感覺目前的工作與生活非常能讓你發揮自己。接下來可以思考的是：你最想把這些優勢帶到哪裡？`

不得把 40% 解讀成「你有 60% 天賦被浪費」。

## 8. AI Report 固定結構

AI 只能輸出：

1. `重複出現的線索`
2. `可能的原動力`
3. `目前可能存在的張力`
4. `可以探索的方向`
5. `給自己的下一個問題`

方向順序優先：

1. 現職調整
2. 小型副專案
3. 興趣發展
4. 專業輸出
5. 第二收入
6. 第二曲線

不得第一句就導向創業、業務或特定商業機會。

## 9. 內容優先級

若不同來源互相衝突：

1. 本人明確回饋
2. RIASEC 與本人選擇
3. 當前工作／生活現況
4. Life Path 象徵性描述

Life Path 永遠不能蓋過本人對自己的描述。
