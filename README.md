# talent-motivation

天賦原動力探索系統。

核心主題：

> 看見天賦、找到原動力、增加人生的選擇。

目前採三面鏡子架構：

1. Life Path — 自我反思入口
2. RIASEC — 職涯興趣 / 活動偏好
3. 本人現況 — 天賦使用感、優先需求與探索意願

## Current status

目前尚未開始正式 P0 程式開發，先完成 legacy `innernumber` audit 與新版計算規格鎖定。

## Planned stack

- React + TypeScript + Vite
- Tailwind CSS
- LINE LIFF / LINE Login
- Lark Base + Lark OpenAPI
- Vercel
- LLM structured analysis

## Design principle

> 程式負責算；LLM 負責理解；本人負責驗證。

> 整合解讀，不整合計分。
